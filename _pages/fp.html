About Future Pinball

Future Pinball has been around for many years. It is a platform that allows creators to build tables without using ROMs. Unfortunately Future Pinball development stopped in 2010.

There are excellent tables on Future Pinball. Some very good table designers like Terry Red, SlamTilt, Shiva, Ravarcade and many more have created breathtaking tables.

BAM — Better Arcade Mode

A major game changer for Future Pinball is the amazing work from Ravarcade, creator of BAM (Better Arcade Mode). The freeware is available to download for free and is a must in order to run any modern FP tables. Ravarcade also offers an all-in-one installer for Future Pinball and BAM — this will optimize the perspective of your gameplay.

⚠️ BAM is required to run most modern Future Pinball tables.

BAM Features

  • Future Pinball bugs fixed
  • Light settings
  • Per-pixel lighting and new rendering engine
  • Camera settings (work in progress)
  • Post-processing effects (blur, gamma correction, brightness, saturation)
  • Plugin system
  • Improved high score (values above 2 billion)
  • New features on tables (custom game rooms, custom balls, animated mini-playfields)
  • Physics settings defined per table
  • All for free — BAM is Freeware

BAM for Pinball Cabinet

  • BAM view — perspective calculated for viewer eye position
  • Head-tracking — best way to recreate the impression of a real pinball machine
  • Stereo 3D — many glasses and display types supported
  • Easy to setup table position/size and back-box position/size
  • Special effects designed for cabs

BAM for VR

  • All main VR headsets supported: Oculus Rift, HTC Vive, phone headset via OpenVR and RiftCat
  • Room scale and sitting modes
