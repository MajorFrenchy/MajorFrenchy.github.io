Pinball FX is the successor to the very popular Zen Studios Pinball FX3. Many tables have been ported to this new platform. This is commercial software — tables must be purchased. Great titles include Indiana Jones and Jurassic Park. The strength of Pinball FX is the stunning 3D animations built into the tables.

Store

Tables can be purchased on multiple platforms. Unfortunately, buying on one platform does not grant access on another — and those who purchased all tables for Pinball FX3 will need to repurchase them for FX.

🎮 Steam 🎮 PlayStation 🎮 Xbox 🎮 Nintendo Switch

Cabinet Installation

You will need Steam installed on your PC to run Pinball FX. Once installed, purchase tables on Steam or within the game (which redirects back to Steam).

Once Pinball FX is launched you can set up cabinet mode and configure your screens.

Step 1 — Configure Cabinet Screens

The cabinet settings tab lets you set the Width, Height, Horizontal and Vertical position of the DMD and Backglass for each of your displays.

A helpful visual feature: the perimeter of each window glows so you can clearly see exactly where it sits on screen while positioning it.

Step 2 — Install Backglasses

By default Pinball FX includes no backglasses. Download them from the community links below and install them here:

C:\Program Files (x86)\Steam\steamapps\common\Pinball FX\PinballFX\Mods\Cabinet

The filename must exactly match the table's internal name (e.g. Table_109 for Medieval Madness). Use the searchable list below to find any table's number.

Adding Pinball FX to PinUP Popper

Nailbuster (creator of PinUP Popper) has full instructions on his wiki:
nailbuster.com/wikipinup — Pinball FX Stream

Step 1 — Add a New Emulator

In Emulator Setup, press + to add a new emulator. Fill in all red fields (paths and game extension). The game extension is pxp. Press the checkmark when done.

Step 2 — Add Launch & Close Scripts

Add the launch and close scripts for Pinball FX. Get the latest scripts directly from Nailbuster's site — they get updated so there's no point reposting them here:
nailbuster.com/wikipinup — Pinball FX Stream

Step 3 — Import Games

Go to Game Manager, right-click in the left pane, and select Import New Games from file. The import file is provided by Nailbuster — find it at the link above.

You are now ready to set up media for your Pinball FX tables. See the PinUP Popper page for help with media setup.
