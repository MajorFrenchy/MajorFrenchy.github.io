Visual Pinball X

Visual Pinball is the most used platform among the Virtual Pinball community. There is a very large community creating original tables such as Harry Potter and the Goblet of Fire (Original) by Scott Wickberg of Orbitalpin.com, the Iron Maiden Legacy of the Beast (Original) from members of the VpinWorkshop team, or real table recreations like JP's Indiana Jones (Stern 2008) by JPSalas.

VPX Features

  • Simulates pinball table physics and renders the table with DirectX or OpenGL
  • Simple editor to (re-)create any kind of pinball table
  • Live editing in the rendered viewport
  • Table logic and game rules controlled via Visual Basic Script
  • Over 1050 real/unique pinball machines from ~100 manufacturers, plus over 550 original creations
  • Emulation of real pinball machines via Visual PinMAME
  • Configurable camera views for correct display in virtual pinball cabinets
  • Support for Tablet/Touch input or specialized pinball controllers
  • Support for Stereo3D output and Head tracking via BAM
  • Support for VR HMD rendering including PUP, B2S backglass and DMD output

Installing Visual Pinball

Click any image to enlarge it.

1

Download from trusted source

Download Visual Pinball X from the official Github. Download the full installer 1st before upgrading to 10.8.

2

Unblocking

Right click on the installation file and select properties.

3

Selecting Unblock

Check the unblock box and apply.

4

Launching the Visual Pinball installation file

Just like any other program, double click to install and follow the prompts.

5

Installation path

You can install it anywhere. A good practice is to create a folder (e.g. Vpinball) and install all software in it. Remember the path for future use.

6

Visual Pinball Options

Select B2S Backglass and .Net. If you have a real DMD, you can select PinDMD.

7

Launching VisualPinballX

Double click the desktop shortcut. Go to Preferences → Video/Graphic options.

8

Visual Pinball Video options

Select your video card and resolution. Uncheck Force Exclusive Fullscreen. Adjust the texture slider to reduce lag or memory errors. Ambient occlusion can also cause memory errors.

9

VPS — Virtual Pinball Spreadsheet

Find any table by keyword — hosting site, version, ROM, Backglass, POV, and Media files all in one place. Site: virtual-pinball-spreadsheet.web.app

10

Table Hosts

Tables are hosted on VPUniverse, VPForums and Pinball Nirvana. The location is decided by the table author(s).

11

About this file

Take the time to familiarize yourself with important details such as what version of software is required.

12

ROMs

Tables recreated from real pinball machines require a ROM for emulation. Original tables do not. The VPS site links to ROM downloads for each table.

13

Downloading the Backglass

On the VPS site, Backglasses are also listed. Download one and extract it in the VisualPinball/Table folder.

14

Renaming the backglass

Rename the .directb2s file to match your table name, keeping the .directB2S extension. Move it to your VisualPinball/Table folder.

15

Launching VPX

Double click the desktop shortcut, select File → Open and pick a VPX table to open it in editor mode.

16

Editor Mode

In this mode you can view the script, launch the Interactive view, and of course launch the table.

17

Launching the table

Press F5 or the launch icon shown in the picture to launch the table.

18

Play!

The table will launch and bring you joy. If you get an error, it is most likely due to the wrong version of software — upgrade to the minimum specs (e.g. VPX 10.8 + Vpinmame 3.6).

Upgrading VPX to a Newer Version

1

Check your current VPX version

Open Visual Pinball X and in the Help menu select About.

2

Download a newer VPX

You only need the full install once. Any upgrade just requires dropping in a few files. Always backup old files first. Beta versions are on Github.

3

VPX Beta

You will see many versions (Debug, GL…). Pick the Release-Win version. X86 version is fine for now.

4

Always unblock

Right click the file → Properties → check the Unblock box → Apply.

5

Extract the Zip

Extract the archive contents.

6

Copy and replace VPX — You are Done

Select the files from the new VPX archive and move them into your VisualPinball folder. When asked to overwrite, say Yes.

Upgrading VPinMAME

1

Check your current Vpinmame version

Navigate to your VisualPinball/Vpinmame folder and double click Setup.exe.

2

Version

It will tell you what version you currently have installed.

3

Vpinmame Github

Pick the Release-Win version. X86 is fine. Go to Vpinmame Github.

4

Always unblock

Right click the file → Properties → Unblock → Apply.

5

Extract the Zip

Extract the archive contents.

6

Copy and replace Vpinmame

Be careful if you have a VPMalias file with content — keep the old one. Copy and replace all other files in the Vpinmame folder.

7

Install the Newer Vpinmame

In the Vpinmame folder, open Setup.exe. The highlighted version should reflect the new version. Click Install and follow the prompts.

8

Check your Paths again

Click the Path button and make sure your paths are set correctly.

9

🎉 You Did It!

You just upgraded VPX and Vpinmame to the latest versions. Time to play some pinball.
